# Agent Skills

A curated collection of specialized agentic skills for iOS reverse engineering, binary analysis, and device instrumentation.

## Included Skills

| Skill | Description |
| :--- | :--- |
| [`ida-pro-mcp`](./ida-pro-mcp/) | Workflow guide and tool reference for reverse engineering binaries with IDA Pro MCP. |
| [`ipsw-extract-component`](./ipsw-extract-component/) | Extract target daemons, frameworks, and dyld shared caches from iOS IPSWs on Windows. |
| [`pymobiledevice3`](./pymobiledevice3/) | Inspect, instrument, automate, and debug Apple devices via `pymobiledevice3`. |
